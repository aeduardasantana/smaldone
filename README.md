# Smaldone

Marketplace de conexão entre quem precisa de acessibilidade em Libras e profissionais intérpretes.

## Estado atual
A capa pública foi estruturada para apresentar a proposta do produto sem simular funcionalidades ainda não implementadas.

## Arquitetura pública planejada
- Home
- Encontrar intérprete
- Sou intérprete
- Como funciona
- Entrar

Os fluxos de cadastro, perfis, busca e contratação serão implementados em etapas posteriores.

## Ecossistema
Smaldone é uma solução do ecossistema GEB, com desenvolvimento tecnológico pela Compass Rose Systems.
